## 64비트 함수 호출 규약 (Calling Convention)

### 1. System V AMD64 ABI (Linux / macOS 등)

| 인자 순서 | 레지스터 | 설명 |
|---|---|---|
| 1번째 | `RDI` | 첫 번째 인자 |
| 2번째 | `RSI` | 두 번째 인자 |
| 3번째 | `RDX` | 세 번째 인자 |
| 4번째 | `RCX` | 네 번째 인자 |
| 5번째 | `R8` | 다섯 번째 인자 |
| 6번째 | `R9` | 여섯 번째 인자 |
| 7번째부터 | 스택 | 추가 인자 |

> 정수 및 포인터 인자 기준이며, 부동소수점 인자는 별도 레지스터를 사용한다.

---

### 2. x86-64 Windows (Microsoft x64 Calling Convention)

Windows는 System V와 인자 전달에 사용하는 레지스터가 다르다.

| 인자 순서 | 레지스터 | 설명 |
|---|---|---|
| 1번째 | `RCX` | 첫 번째 인자 |
| 2번째 | `RDX` | 두 번째 인자 |
| 3번째 | `R8` | 세 번째 인자 |
| 4번째 | `R9` | 네 번째 인자 |
| 5번째부터 | 스택 | 추가 인자 |

> Windows x64에서는 호출자가 32바이트의 Shadow Space를 확보해야 한다.

---

### 3. 비교

| 구분 | System V AMD64 | Windows x64 |
|---|---|---|
| 1번째 | `RDI` | `RCX` |
| 2번째 | `RSI` | `RDX` |
| 3번째 | `RDX` | `R8` |
| 4번째 | `RCX` | `R9` |
| 5번째 | `R8` | 스택 |
| 6번째 | `R9` | 스택 |
| 7번째부터 | 스택 | 스택 |
| 반환값 | `RAX` | `RAX` |
| 스택 정렬 | 16바이트 | 16바이트 |
